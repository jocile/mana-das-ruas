Um projeto de website para a organização social **Maná das Ruas**, dedicada a ajudar pessoas em situação de rua, fornecendo alimentação e apoio às comunidades carentes.

---

## 📖 Sobre o Projeto

O **Maná das Ruas** é um grupo de apoio que trabalha ativamente para cuidar de irmãos em situação de rua, oferecendo refeições quentes, acolhimento e assistência humanitária. Este website serve como uma plataforma digital para:

- Divulgar o trabalho da organização
- Atrair voluntários e doações
- Informar o público sobre nossas atividades e horários
- Facilitar o contato com nossa equipe

---

## ✨ Funcionalidades

- 📱 **Design totalmente responsivo** – Funciona perfeitamente em desktop, tablet e mobile
- 🍲 **Seção de Serviços** – Informações sobre sopão, quentinha e doações
- 📸 **Galeria/Portfólio** – Registro visual de nossas ações e eventos
- 📅 **História da Organização** – Linha do tempo do desenvolvimento do projeto
- 👥 **Equipe** – Apresentação dos membros que compõem o grupo
- 📧 **Formulário de Contato** – Facilita a comunicação com nossa equipe
- 🔗 **Redes Sociais** – Integração com Twitter, Facebook e LinkedIn

## 🚀 Como Usar

### Requisitos
- Qualquer navegador web moderno (Chrome, Firefox, Safari, Edge)

### Passos

1. **Clone o repositório** ou baixe os arquivos
2. **Abra o arquivo** `index.html` diretamente no seu navegador
3. **Navegue pelo site** usando o menu superior

> **Nota:** Não é necessário configurar servidor local – o site funciona diretamente pelo sistema de arquivos.
